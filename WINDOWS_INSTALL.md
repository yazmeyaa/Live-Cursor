# Установка Laplas Cowork на Windows

Laplas Cowork устанавливается в папку конкретного хранилища Obsidian. Если у вас несколько хранилищ, повторите установку для каждого из них.

## Требования

- Windows 10 или Windows 11.
- Установленный [Obsidian](https://obsidian.md/download).
- Открытое локальное хранилище Obsidian.
- Для подключения других устройств: одна локальная сеть или VPN, например Tailscale.

## Вариант 1: установка из GitHub Release

Это рекомендуемый способ.

1. Откройте страницу [Releases](https://github.com/yazmeyaa/Live-Cursor/releases).
2. Откройте последний релиз и скачайте:

   - `main.js`
   - `manifest.json`

3. Откройте папку вашего хранилища Obsidian в Проводнике.
4. Перейдите в каталог:

   ```text
   <папка-хранилища>\.obsidian\plugins
   ```

5. Создайте внутри него папку:

   ```text
   laplas-cowork
   ```

6. Поместите скачанные файлы в эту папку. В результате структура должна выглядеть так:

   ```text
   <папка-хранилища>\
   └── .obsidian\
       └── plugins\
           └── laplas-cowork\
               ├── main.js
               └── manifest.json
   ```

7. Полностью перезапустите Obsidian.
8. Откройте **Настройки → Сторонние плагины**.
9. Если включён безопасный режим, разрешите использование сторонних плагинов.
10. Найдите **Laplas Cowork** в списке установленных плагинов и включите его.

## Вариант 2: сборка из исходников

Этот вариант предназначен для разработки или проверки последней версии.

### Дополнительные требования

- [Git for Windows](https://git-scm.com/download/win).
- [Node.js](https://nodejs.org/) версии 20 или новее.

Откройте PowerShell и выполните:

```powershell
git clone https://github.com/yazmeyaa/Live-Cursor.git
Set-Location Live-Cursor

npm ci --legacy-peer-deps
npm run typecheck
npm test
npm run build
```

Укажите путь к своему хранилищу и установите собранные файлы:

```powershell
$VaultPath = "C:\Users\YOUR_NAME\Documents\Obsidian\MyVault"
$PluginPath = Join-Path $VaultPath ".obsidian\plugins\laplas-cowork"

New-Item -ItemType Directory -Force -Path $PluginPath | Out-Null
Copy-Item ".\main.js" $PluginPath -Force
Copy-Item ".\manifest.json" $PluginPath -Force
```

После копирования полностью перезапустите Obsidian и включите **Laplas Cowork** в разделе сторонних плагинов.

## Запуск локального сервера

Один Windows-компьютер может выступать сервером синхронизации для остальных устройств.

1. Откройте **Настройки → Laplas Cowork**.
2. Оставьте адрес сервера:

   ```text
   ws://localhost:4444
   ```

3. Скопируйте автоматически созданный **Shared Secret** и сохраните его в безопасном месте.
4. Нажмите **Start Local Server**.
5. Если Windows Defender Firewall запросит разрешение, разрешите доступ только для частных сетей.

Компьютер с сервером должен оставаться включённым, а Obsidian — запущенным.

## Подключение другого устройства

### 1. Узнайте IP-адрес сервера

На компьютере-сервере откройте PowerShell:

```powershell
ipconfig
```

Найдите строку **IPv4 Address** у активного сетевого адаптера. Например:

```text
192.168.1.25
```

### 2. Настройте клиент

На втором устройстве откройте настройки Laplas Cowork и укажите:

```text
Server Connection URL: ws://192.168.1.25:4444
Room Name: то же значение, что на сервере
Shared Secret: тот же секрет, что на сервере
```

Замените `192.168.1.25` на реальный IP-адрес вашего Windows-компьютера.

Не используйте `localhost` на втором устройстве: этот адрес всегда указывает на само устройство, а не на компьютер-сервер.

## Настройка Windows Firewall вручную

Если устройства не подключаются:

1. Откройте **Безопасность Windows → Брандмауэр и защита сети**.
2. Выберите **Разрешить работу с приложением через брандмауэр**.
3. Разрешите Obsidian входящие подключения для частной сети.
4. Не открывайте порт `4444` для публичных сетей без защищённого VPN или TLS-прокси.

Проверить доступность сервера со второго Windows-компьютера можно командой:

```powershell
Test-NetConnection 192.168.1.25 -Port 4444
```

При успешном подключении поле `TcpTestSucceeded` должно иметь значение `True`.

## Обновление

1. Скачайте новые `main.js` и `manifest.json` со страницы Releases.
2. Закройте Obsidian.
3. Замените файлы в `.obsidian\plugins\laplas-cowork`.
4. Снова запустите Obsidian.

Папку `data` удалять не нужно: в ней находятся служебное состояние и локальная база сервера.

## Удаление

1. Отключите Laplas Cowork в настройках Obsidian.
2. Полностью закройте Obsidian.
3. Удалите папку:

   ```text
   <папка-хранилища>\.obsidian\plugins\laplas-cowork
   ```

Удаление папки также удалит локальную базу сервера этого хранилища. Перед удалением сделайте резервную копию важных данных.

## Частые проблемы

### Плагин не появился в списке

- Проверьте точное имя папки: `laplas-cowork`.
- Убедитесь, что `main.js` и `manifest.json` лежат непосредственно в ней, без дополнительной вложенной папки.
- Полностью перезапустите Obsidian.

### Сервер не запускается

- Убедитесь, что порт `4444` не занят другим приложением.
- Проверьте журнал разработчика Obsidian: **Ctrl+Shift+I → Console**.
- Перезапустите Obsidian и попробуйте снова.

### Второе устройство не подключается

- На обоих устройствах должны совпадать `Room Name` и `Shared Secret`.
- Используйте IP-адрес сервера, а не `localhost`.
- Проверьте Windows Firewall и выполните `Test-NetConnection`.
- Убедитесь, что оба устройства находятся в одной сети или подключены к одному VPN.

### Подключение через интернет

Не публикуйте обычный адрес `ws://` напрямую в интернет. Используйте VPN либо TLS reverse proxy с адресом `wss://`. Shared Secret ограничивает доступ, но содержимое хранилища не имеет сквозного шифрования со стороны Laplas Cowork.
